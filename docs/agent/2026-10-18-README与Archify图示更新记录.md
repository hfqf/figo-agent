## 4. GIF 导出

导出脚本：[export-diagrams.mjs](assets/2026-10-18-readme/export-diagrams.mjs)。从仓库根目录执行：

```bash
node docs/agent/assets/2026-10-18-readme/export-diagrams.mjs
```

需要现有 `code/node_modules` 中的 `playwright-core`、本机 Chrome 和 FFmpeg。可通过 `CHROME_EXECUTABLE`、`FFMPEG_EXECUTABLE` 指定可执行文件路径。

脚本先校验 HTML 与 passing finalize 回执哈希，再用 Chrome 操作 Archify 自带的导出菜单：

```text
已校验 HTML
    -> Archify 原生 PNG / 浅色 SVG
    -> Archify 原生 6 秒 WebM
    -> FFmpeg 调色板生成与 GIF 转码
    -> 1440px、12fps、无限循环 GIF
```

不是截取工作台页面，不读取用户 SQLite，不手绘替代原图，不额外编造运行轨迹。WebM 保存在忽略目录 `.archify/workflow-readme-20261018-160140/exports/`；PNG、SVG、GIF 和导出哈希保存在文档附件中。[导出清单](assets/2026-10-18-readme/exports.json)记录对应文件哈希，WebM 可由已保存 HTML 重导。

实际 GIF 为 1440×704、73 帧、约 6.08 秒、1084607 字节。逐帧解码得到 61 个不同帧哈希，确认并非静态图片改扩展名。已查看中段解码帧，节点、标签和流转高亮可见；静态 PNG 提供更高分辨率的文字检查入口。

**动效只用于解释逻辑流向，不表示真实模型耗时、执行顺序采样、成本或 Trace 回放。** 页面禁止动画、无法预览 GIF 或需要打印时，可使用相邻静态 PNG 链接。
