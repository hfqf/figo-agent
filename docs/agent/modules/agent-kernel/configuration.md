# 配置与文案边界

## 分类原则

| 类型 | 所属位置 | 示例 | 依据 |
| :--- | :--- | :--- | :--- |
| 可调运行参数 | `code/figo-agent.config.json` | 模型选择、压缩阈值、工具默认超时、文件搜索上限 | 改值应改变程序行为，启动时校验 |
| 固定显示文案和固定 Agent 提示模板 | `code/locales/zh-CN.json` | 按钮名称、错误兜底、压缩指令模板 | 改文案不应改变权限和阈值；目前只有中文资源 |
| 用户编辑的提示词 | `code/.figo-agent/prompts.json` | 自定义系统指令、持久用户指令 | 属于本机用户数据，独立版本指纹和冲突校验，不进入版本库 |
| 协议与安全边界 | TypeScript 代码 | API 路由、SQL、危险命令拒绝、工具输入上限 | 外部数据不得绕过程序安全约束 |

运行参数经 `loadRuntimeConfig` 解析、校验后，由 `AgentKernel` 与内置插件装配注入 Agent/Tool；`LocalApi` 从同一份配置接收文件和终端参数，并只把文件区/终端需要的非敏感参数投影到 `/api/v1/bootstrap`。浏览器不读取运行配置原件或模型密钥。运行中修改参数需要重启；修改用户提示词后新 Turn 读取最新版本。

## 已接入

- `agent.toolResultPreviewChars`：工具结果进入模型消息的预览长度。
- `tools.defaults`：命令、网络、浏览器、Git、批量读取、项目摘要、Skill 摘要、ToolCall 持久化预览的缺省值。
- `web.fileBrowser`：搜索、目录列表、预览和引用限制；搜索门槛及目录显示上限同时投影给前端。
- `web.terminal`：命令长度、历史条数、输出大小及运行超时；命令长度投影给前端。
- `locale`：只接受 `zh-CN`；Agent 固定提示模板与浏览器工作台文案从中文资源读取。
- 工作台提示词独立存储；旧运行配置若含 `prompts`，在独立文件尚不存在时只读回退。

## 尚未完成的文案迁移

浏览器端 `code/web/src` 的中文已统一从资源读取。`code/src/ui/local-api.ts`、工具/策略/配置解析模块仍有直接写在 TypeScript 中的错误与工具描述。这些尚未纳入 `zh-CN` 资源，不能宣称“全站文案已国际化”。后续逐模块迁移时保留稳定的错误码和协议字段，资源只负责显示文字；测试需验证缺失 key、模板占位符与前后端展示一致性。

不迁移的固定值包括：HTTP 路由、数据库表与列名、Trace 事件类型、状态枚举、安全硬上限和文件过滤规则。这些是协议或保护边界，不应作为普通运行参数或翻译字符串暴露。
