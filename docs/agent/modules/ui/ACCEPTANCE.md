## 2. 功能与证据用例

1. 从首屏创建 Task、提交普通文本、看到 `accepted/running/completed` 或失败；同一文本重复发送的幂等键不创建第二个 Turn、第二次模型请求或第二次 Tool 执行。
2. Task 切换后对话、ContextPack、抓包、Trace 全部同步换范围；历史 Session 首期可读但不允许假装已恢复执行。
3. 点击文件只读取已有文本，不创建 Turn、ToolCall、ContextItem 或 LLM 请求；显式保存仅产生 `file.saved` UI 事件。选中已保存的行并引用后，服务端重读并校验版本，发送的 Turn 中有可追溯文件来源与行区间。
4. 保存时文件版本已变、越界符号链接、敏感配置、二进制和超大文件分别得到明确拒绝/受限结果；不泄漏绝对路径或 API Key。未保存草稿禁止引用，关闭或切换文件须确认。
5. 上下文检查器的纳入/排除、原因、估算和压缩边界与 SQLite 一致；估算绝不显示成 Provider 实际 Token。
6. 抓包视图覆盖普通 Turn、Task 压缩与轮次压缩请求；无 usage 时显示“未提供”，`partial` 不补零；HTTP 失败保留请求、状态与错误。
7. Trace 依稳定次序显示事件；点击任意事件后，侧栏保留列表、左侧主工作区立即展示对应详情，切换事件时详情回到顶部。文件窗口可切回且未保存草稿不丢；窄屏须露出详情。关联跳转仅在真实键存在时提供，不以时间相近冒充关联，不呈现模型隐藏思维链。
8. 页面刷新、SSE 断连重连和服务进程中断后，历史事实不丢、不重复执行有副作用 Tool；未完成 Run 标成 `interrupted`。
9. CLI 原有 Task、Tool Calling、压缩、TokenUsage 自动化测试继续通过；UI 适配层不改变已有行为和 SQLite 时间格式。

## 3. 安全与视觉用例

1. 从非本机网卡连接失败；错误 Host/Origin、无本地会话、跨站写请求与未授权 SSE 均被拒绝。认证凭证、模型密钥不进入 JS 包、URL、Trace、抓包显示或浏览器持久存储。
2. 浏览器发起 Tool 的路径仍经过 `ControlledToolPolicy`；Policy 拒绝在 UI 和 Trace 中一致。未经单独验收，不能增加“批准执行”或“取消执行”按钮。
3. 抓包默认掩码 Header 与敏感正文，不返回未经脱敏的原始 SQLite 记录；复制与下载遵循同一脱敏规则。
4. 以 `figox/shots/` 三张图为视觉参照，按确认的左文件树、中间编辑器、右侧 Task 列表/对话一体面板检查 1440x900 桌面、1024x768 窄桌面和 390x844 移动视口：列表点击后原位进入对话，返回可恢复列表；无文字/控件重叠，分析侧栏可收起，代码与侧栏可独立滚动。
5. 交互测试覆盖键盘焦点、图标按钮名称、长中文 Task 标题、长 UUID、空态、失败态、失联态与多轮 Tool 事件；不能只用静态截图宣布交互通过。
