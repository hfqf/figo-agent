## 已实现接入方式

1. 工作台初始化成功后，首次展示总览图片；首次进入 Trace Inspector 展示专属图片。模型未配置、正在显示设置或工作区选择窗口时，不自动覆盖这些入口。
2. 点击图上或图外任意位置立即关闭，并拦截这次点击，不能误触底层的发送、设置或文件操作；Escape 同样关闭。
3. 已看状态保存在配置根目录的 `.figo-agent/onboarding.db`，表为 `onboarding_views`，主键是 `guide_id + revision`，时间为上海时间、精确到毫秒。它不随工作区切换，也不依赖端口相关的 localStorage；重复关闭幂等，不覆盖首次已看时间。
4. 设置页新增“使用引导”，分别重看任一图片；不新增顶部按钮。素材版本独立于产品版本，产品小升级不自动强制重看。存在未保存设置时，重看前沿用原有离开确认。
5. 两张图等比完整展示，不裁掉数字和说明；1440、390、320 px 已验证不越界。当前素材仍是横向桌面图片，窄屏缩小后的文字阅读体验未做专门优化，不宣称已交付纵向版。
6. `code/figo-agent.config.json` 的 `web.onboarding.enabled` 控制自动展示，`revision` 控制素材版本，启动时读取；关闭自动展示后，设置页仍可主动重看。默认值分别为 `true`、`"1"`。中文替代说明、错误提示和标题集中于 `code/locales/zh-CN.json` 的 `onboarding` 资源。
7. 图片由 Vite 作为带哈希的静态资源打入 Web 产物；后续 Electron 打包复用这些产物，不依赖生成工具目录或开发机路径。引导不创建 Task、Turn，不调用模型，不进入模型上下文。

## 模块边界与失败处理

- `OnboardingStore` 只读写引导已看记录；不扩充 AgentKernel 或工作区数据表。
- `PUT /api/v1/settings/onboarding` 沿用 Host、Origin、本机会话和 CSRF 保护，校验固定图名和当前素材版本。Bootstrap 只返回开关、版本和已看图名。
- `Onboarding` 根据当前页面、服务端快照和页面内已关闭记录选择图片；`GuidePicture` 使用原生模态 dialog 阻止点击和键盘穿透。Tab 保持在关闭入口，Escape、Enter、空格与任意位置点击均可关闭。
- 图片未加载成功不写已看记录；加载失败提供可退出提示。缓存命中的图片按 DOM 的 `complete + naturalWidth` 判断，不仅依赖异步 `onLoad`。
- 保存失败立即关闭、显示中文错误，本页面不反复弹出；下次进入重试。初始化存储不可用时禁用自动展示，不阻断工作台启动。

## 经验与剩余边界

动态端口应用的长期 UI 偏好应存配置根目录，而不是依赖每个 Origin 的浏览器存储；图片内容不是可交互控件，关闭行为必须由外部组件承担。验收要区分“Trace Inspector 自身的 dialog”和“引导 dialog”，不能把正常检查器窗口计为重复引导。

初次接入只验收本地 Web；后续瘦身构建已包含两张图片，并通过 Mac 包内引导解码和关闭检查。Windows 未做实机运行。窄屏纵向素材、图片内标注与实时控件自动对齐均不在本轮范围。
