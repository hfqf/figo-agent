# 桌面安装包瘦身与对照验收

日期：2026-10-18。产品版本仍为 `0.0.1-beta`，不修改 Agent、模型、SQLite 或工作区数据。交付新的 Mac arm64 ZIP 与 Windows x64 NSIS 安装器，均未签名。

## 本轮范围

只实施两项低风险裁剪，不更换桌面架构，不删除浏览器、Node.js、SQLite、图形驱动、媒体组件或许可证。

1. Electron 解压后、应用装配和签名之前，保留简体中文和英文回退语言资源。Windows 保留 `zh-CN.pak`、`en-US.pak`；Mac 保留 `zh_CN`、`en` 及对应性别变体。必要回退资源缺失时拒绝构建，不先删剩余语言。
2. Forge 应用归档改为运行内容白名单：编译后服务、构建后的 Web、中文资源、主进程所需 logo、`package.json`、预加载入口和第三方许可。移除锁文件、npm/构建配置、构建脚本、类型声明、Source Map、Web 源码和原始引导图。两张经过 Vite 打包的引导图保留。

实现位于 `code/scripts/desktop-package-content.cjs`，通过 `code/forge.config.cjs` 的 `ignore` 与 `afterExtract` 接入。同一规则用于两个平台，裁剪仅发生于本次构建目录，不改下载缓存或开发资源。运行配置与密钥仍被全路径拒绝，不因允许某个目录而放行目录内敏感文件。

## 配对方法

此前 Mac 包未包含最新引导，不能直接与当前新版比较。先以当前代码重建完整语言版 Mac 基线，再与瘦身版比较；Windows 使用上一轮同代码、同版本的完整语言版安装器。

`code/e2e/desktop-size-report.mjs` 记录文件逻辑字节数、安装器 SHA-256、应用归档体积、语言数量，以及编译后业务代码、Web 产物和应用中文资源的内容哈希。该内容哈希不代表 Electron 引擎二进制哈希。

两个平台的前后业务与界面内容哈希均为：

```text
115437275aea24a17e2195ba2df36f6455f13cd9ad989041d497e2f7026e5373
```

原始报告保存在 [baseline.json](./assets/size-2026-10-18/baseline.json) 和 [optimized.json](./assets/size-2026-10-18/optimized.json)。本地旧安装器备份于 `code/out/size-comparison/original/`，配对基线备份于 `code/out/size-comparison/baseline/`；二进制备份不进入 Git。

## 实际收益

单位为 MiB，1 MiB = 1,048,576 字节；不使用文件系统预分配或块占用代替下载体积。

| 指标 | Mac 前 → 后 | Windows 前 → 后 |
| --- | --- | --- |
| 下载体积 | 127.96 → 114.09，减少 10.84% | 111.04 → 101.64，减少 8.46% |
| 解压后体积 | 294.88 → 245.74，减少 16.66% | 375.24 → 325.92，减少 13.14% |
| 应用归档 | 7.35 → 5.20 | 7.35 → 5.20 |
| Electron 语言条目 | 220 → 8（含性别变体） | 55 → 2 |
| 语言资源字节数 | 50,367,539 → 1,173,617 | 50,643,495 → 1,178,663 |

解压后各减少约 49 MiB。语言文本本来就有较高压缩率，因此删除约 48 MiB 语言资源，不等于下载包减少同样体积。安装包仍在百兆级，主要运行时未改变；不宣称本轮达到数十兆级安装包。

## 可复用经验

先把下载体积、安装后体积和业务归档分开，再选择占比明确的项目。保持版本、业务代码、界面资源及压缩方式一致，才能归因于打包裁剪。运行时库不能仅凭文件名“看起来没用”就删除；本轮以约 8%-11% 下载缩减换取边界可控，而不是用缺失功能换体积。
